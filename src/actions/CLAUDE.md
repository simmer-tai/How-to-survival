# actions/（プレイヤーの行動）

伐採・採取・岩を掘る・地面を掘る・木を植える・建築・クラフト・焚火・食べる・飲む・釣り・船・槍。入力の判定と、その結果で世界を変える処理がここにある。

> **このフォルダのファイルを追加・削除・変更したら、この CLAUDE.md の内容も合わせて見直し、必要なら書き換えること。**
> ルートの `CLAUDE.md` のフォルダ構成の表や「開発方針」の「現状」（どの操作がワールドコマンドになっているか）に関わる変更なら、そちらも直す。

## ファイル

| ファイル | 中身 | 状態の種類・コマンド |
|---|---|---|
| `chopping.ts` | 木を斧で切り倒す（`TreeChopper`）。木は木の番号で持つ（最初から島にある木は props の生成順、種から育てた木は `planting.ts` の `PLANTED_TREE_BASE` + 植えた木の番号で `addTree()` する。丸太をばらし終えると `onRemove`）。倒れた丸太は物理で動き、マルチではその場所の物理の担当が計算した位置（`motion()`）をほかの人に配る（`setMotion()`）。丸太をばらしたときの木材は、ホストが世界の頼みとして `dropItem` で出す | 共有：`chopTree` |
| `foraging.ts` | 茂みの採取（`BushForager`）。叩いた耐久値の割合に合わせて少しずつ手に入る。実は生え直す | 共有：`harvestBush`・`pickBerry` |
| `mining.ts` | 岩を石のツルハシで叩く（`RockMiner`）。石がインベントリに入り、壊れると岩は塊にばらけて消える | 共有：`mineRock` |
| `digging.ts` | 木のスコップで自分の島の地面を掘る（`GroundDigger`）。土がインベントリに入る。穴は土を持って右クリックすると土1つで埋まり、掘ってから18分たつとひとりでに埋まる。木の種を持って右クリックすると穴の底に種を置け（ほかの木や種を置いた穴のそばは不可）、種を置いた穴が埋まると `onSprout` で苗が生える。穴は地面の下にお椀形を描き、穴の口の上だけ深さを書き込む面で地面を描かせないことで見せる。歩くときの地面の当たり判定は変えない | 共有：`digHole`・`fillHole`・`plantSeed` |
| `planting.ts` | 種から育つ木（`Saplings`）。苗の種類（砂浜ではヤシ、ほかは針葉樹か広葉樹）・形は植えた木の番号（種を置いた穴の番号）から `world/props.ts` の `plantedTree()` で決める。苗は生えてからの時間（`GROW_TIME`）で大きくなり（全員が `tick` で進めて見せる）、育ちきると世界の頼み `growTree` で斧で切れる木として `TreeChopper` に渡す。育ちきった木の切られ具合も、植えた木と一緒に保存する | 共有：`growTree` |
| `pieces.ts` | 建築部材の形（`PIECES`、`CELL`、作業台・焚火の寸法）。部材のアイコン用モデル。製図台は作業台と同じ大きさで、天板に海図・インク壺と羽ペン、棚に巻いた地図を飾る | — |
| `build.ts` | 建築（`Builder`）。ハンマーを持って右クリックで部材を選び、素材（`items/recipes.ts` の `BUILD_PLANS`）から建てる。作業台・製図台・焚火はアイテムとして手に持って置き、グリッドに沿わず狙った所に置ける（部材の上は床・土台にだけ置ける）。ハンマーで解体すると、部材に入れてある物（`contents`。焚火の燃料）も戻る | 共有：`placePiece`・`removePiece`・`hitPiece` |
| `campfire.ts` | 焚火の燃料と火（`Campfires`）。部材の番号ごとに燃料の欄（1種類だけ入る）と、今燃えている燃料ののこり時間を持つ。燃料と1つが燃える時間は `FUELS`。消えている焚火に燃料を入れるとすぐ燃え上がり、燃え尽きると欄から次の1つを燃やす（`tick` は全員が進めて残り時間を見せるが、次を燃やす `burnFuel` は世界の頼みなのでホストのものだけが通る）。取り出した物は、取り出せたと決まってから `onTake` で受け取る。炎・熾火・火の粉・煙（消えたあともしばらくくすぶる）・明かりは自分の画面だけの演出。焚火の部材そのものは `Builder` が持ち、`sync()` で合わせる。低いので、炎のあたりの高さまで狙える（`aimed()`） | 共有：`addFuel`・`takeFuel`・`burnFuel` |

| `food.ts` | 食べる（`Eater`）・飲む（`Drinker`）。食べ物と回復量は `FOODS` | 自分だけ |
| `fishing.ts` | 釣り（`Fisher`）。右クリック長押しで投げ、左クリックで巻く | 自分だけ |
| `boats.ts` | 船（`Boats`）。木製の船を持って左クリックで視線の先の水面に浮かべる。F で乗り降り、W/S で漕いで A/D で向きを変える、Q でしまう。揺れは波の式から決め、物理では動かさない。漕いでいる間の位置は乗っている人が決めて配り（`ridePose`→ほかの人は `follow()`）、降りたときに `leaveBoat` で共有ワールドに書き込む。乗っている人の番号（`rider`）をホストが持ち、降りる・渡るは本人だけができる。場所（`loc`）を持つ。渡り終えたら `onSail` で main が場所を切り替える | 共有：`placeBoat`・`pickBoat`・`boardBoat`・`leaveBoat`・`sailBoat` |

## 共有ワールドを変える行動の書き方

- **入力側と適用側を分ける**。入力側（視線のレイキャスト・キー）は「どの対象に何をするか」を決めて `this.request(req)` を呼ぶだけ
- 時間で起きること（穴が埋まる・苗が育ちきる・燃え尽きる・小石が湧く・丸太の木材）は「世界の頼み」として `this.request(req, null)` にする（マルチではホストのものだけが通る）
- `authorize(req)` で確かめ、ホストが決める値（通し番号の ID、乱数で決まる採れる数、刺さる位置など）を入れてコマンドにする
- `apply(cmd, mine)` はカメラや入力を見ず、コマンドの ID と値だけで世界を変える。採れた物・拾った物などは `mine`（自分の頼み）のときだけ受け取る
- **頼みが通ったかの true は、マルチの参加者では「手元で確かめて送れた」だけ**。受け取る物は `apply` で受け取り、先に減らす物（素材・落とす物など）はホストに断られたときに `main.ts` の `undoRequest()` で戻す
- 型は `core/commands.ts`、振り分けは `main.ts` の `requestWorld()` / `applyWorld()`（詳しくは `core/CLAUDE.md`）
- 状態は `serialize()` / `restore()` で `main.ts` の `snapshot()` に入れる。時間で変わる物は経過時間も保存する。形を変えたら `core/save.ts` の `SAVE_VERSION` を上げる

## 書くときの決まり

- 建築物（焚火も）・刺さった槍・小石・掘った穴・植えた木は自分の島にしかないので、ほかの場所では建てる・槍を投げる・掘るをできなくしている。ほかの場所で何かを置けるようにするときは、その物に `loc` を持たせる
- 木（`chopping.ts`）・茂み（`foraging.ts`）・岩（`mining.ts`）は、海図に載せた島にも島ごとに1組ずつある（`world/isles.ts` が作る）。`at` に `{ loc }` が入っていて、出す頼みとホストが作るコマンドに入れる（main がその島の仕組みへ振り分ける）。番号は島ごとに別々。`RockMiner` は岩の当たり判定を付ける剛体を受け取れる
- 道具を当てて使えたときだけ `main.ts` の `wearTool()` で耐久値を減らす（空振りでは減らさない）
- 木くず・水しぶき・葉が舞うなど自分の画面だけの演出には `Math.random()` を使ってよいが、共有の結果には使わない
- 調整用の数値はファイル先頭に大文字の定数としてコメント付きで置く
