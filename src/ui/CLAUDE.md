# ui/（画面・メニュー・HUD）

タイトル画面、力尽きた画面、チャット、海図、アバターの見た目を選ぶ画面、コマンドメニューなどの UI。UI はすべて**自分だけ**の状態で、同期しない。

> **このフォルダのファイルを追加・削除・変更したら、この CLAUDE.md の内容も合わせて見直し、必要なら書き換えること。**
> ルートの `CLAUDE.md` のフォルダ構成の表に関わる変更なら、そちらも直す。

## ファイル

| ファイル | 中身 |
|---|---|
| `title.ts` | タイトル画面（`showTitle()`。ワールドを選ぶ・作る・消す。「みんなで遊ぶ」で名前を入れ、部屋を開くワールドを選ぶか、部屋コードを入れて参加する。招待リンク `?room=コード` で開くと、部屋コードを入れた状態で始まる）と、画面に一言出す `showToast()` |
| `roomInfo.ts` | 一時停止の画面に出す部屋のようす（`RoomInfo`。部屋にいる人、部屋コード、招待リンク） |
| `death.ts` | HP が尽きたときの画面（`DeathScreen`）。リスポーンかタイトルへ戻るかを選ぶ |
| `chat.ts` | 左上のチャット（`Chat`）。Enter で入力欄を開き、Enter で送る・Esc でやめる。書き込みは10秒たつと消え、開いている間は前の分も見える。「/」で始めるとコマンドメニューの `run()` でコマンドを実行する。マルチでは `main.ts` が `net.say()` でほかの人へ送り、届いた分（`net.onChat`）と人の出入りも書き込む。チャットの高さを CSS 変数 `--chat-h` に入れ、下に並ぶ「やること」（`story/guide.ts`）をその分下げる。日にち・時刻は画面に出さない |
| `seaMap.ts` | 海図（`SeaMap`）。船で世界の端まで行くと開く。視点が船から上空へ昇り（本当の世界を上から描く）、雲を抜けると、すべての場所を小さな模型にした立体の海図になる（模型は自分の画面だけの別の `Scene`。島は場所の地形 `HeightField` から作り、木の位置は場所の id から決める。街は `TOWN_PLAN` から広場と建物を足す）。島か名前の札を左クリックで行き先を選ぶ。Esc で閉じると雲を通って船へ降りる。上空と海図を描く間は `main.ts` の `render()` が `seaMap.render()` に任せる。行き先を選ぶと `onTravel` で `main.ts` が船旅（`voyage.ts`）を始め、その暗転の間に `finish()` で海図の描画をやめる |
| `voyage.ts` | 船旅（`Voyage`）。海図で行き先を選んでから着くまでのロード画面。暗転してから、自分の船が沖を進む場面を描き、画面の下の端から端まで、白い波打つ線（SVG）が伸びて進み具合を出す（文字は出さない。波は流れ続ける）。船旅の間は `body.voyaging` で線のほかの UI をすべて隠す。描くのはゲームの本当のシーンで、海・空・光（`VoyageWorld.keep`）以外の物は描く間だけ隠し、海底は浅瀬のない深い海にする。船は浮かべた船と同じ `boatObject()`・`floatPose()`、漕ぐ人は自分の見た目の `Avatar` で、原点のまわりの大きな円を回って進む。暗くなりきると `onCovered` で `main.ts` が渡る頼み（`sailBoat`）を出し、着いた場所へ切り替えてシェーダーを用意し終えたら `arrive()` を呼ぶ。`SAIL_TIME` より早くは着かず、準備ができるまでは進み具合を止めて待つ（マルチでホストの返事が `GIVE_UP` 秒来なければ元の場所に戻る）。着いたら暗いまま着いた場所を少し描いてから明ける。開いている間はキーとクリックをほかの処理へ渡さない。描く間は `main.ts` の `render()` が `voyage.render()` に任せる |
| `islandChartView.ts` | 島の地図の予想図（`IslandChartView`）。島の地図を持って右クリックで開き、右クリックか Esc でたたむ。左クリックで海図に書き写す（`onCopy`。main がワールドコマンド `chartIsle` にし、地図は1枚なくなる）。組み合わせたメモだけを、地図の種から決めた島の形の上に「？」付きで描く（本当に島にある地形は見せない） |
| `areaMap.ts` | 今いる場所の地図（`AreaMap`）。今はどのアイテムからも開かない（前は地図を持って右クリックで開いていた。島へ渡れるようになったら使い道を決める）。右クリックか Esc でたたむ。今いる場所の地形を真上から見た画像を場所ごとに一度だけ焼き（`addSource()` で登録した地形・桟橋や広場・建物・名前）、その上に自分の位置と向き、同じ場所にいるほかの人を毎フレーム描く |
| `avatarEditor.ts` | アバターの見た目を選ぶ画面（`AvatarEditor`・`AvatarMenu`）。タイトル画面と一時停止の画面から開く |
| `commandMenu.ts` | コマンドメニュー（`CommandMenu`）。0 キーで開き、`/weather rain` のように打つかボタンで実行する。コマンドの中身は `main.ts` で `register()` する（今は天気を変える `/weather`、コインを増やす・減らす `/coin <枚数>`、ほかの場所へ移る `/tp <場所>`）。チャットから「/」で打ったコマンドも `run()` で同じように実行する。ボタンの並びは関数でも渡せて、開くたびに聞き直す（海図に載せた島のように増えるもの） |
| `chargeRing.ts` | クロスヘアの周りの円形のチャージメーター（槍・釣り竿を投げる力） |
| `pickupFeed.ts` | 手に入れた素材を右下に1行ずつ出す |
| `keyGuide.ts` | 操作ガイドの文言の `[左]` `[右長]` `[F]` などを、マウスの絵やキーキャップにする |
| `uiScale.ts` | UI の大きさを画面サイズに合わせる CSS 変数 `--u` |

## 書くときの決まり

- CSS は各モジュールの `injectStyle()` で `<style>` を足す形にする
- 寸法は `calc(N * var(--u))` で書き、画面サイズに追従させる（`uiScale.ts`）
- 色は `core/palette.ts` の `PALETTE` だけ（濃い文字色・縁取りの `#2b2633` は例外）
- 文言は日本語。操作の説明は `keyGuide()` を通してアイコンにする
- 共有ワールドを変えるボタンやコマンド（天気など）は、UI から直接変えず、登録した側（`main.ts`）がワールドコマンドの頼みにする
